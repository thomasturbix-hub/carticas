# Carticas Mágicas

Roguelike de cartas: seis magos, tres actos y una Grieta que baraja el mundo.

**Jugar:** https://thomasturbix-hub.github.io/carticas/

En Android: abre el enlace en Chrome → menú ⋮ → «Instalar aplicación». Funciona sin conexión tras la primera visita.

Iconos de [game-icons.net](https://game-icons.net) (CC BY 3.0) — ver `assets/CREDITOS_ICONOS.txt`.
